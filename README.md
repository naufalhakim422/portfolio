# 🌌 Naufal Hakim Muzaki — Official Portfolio

## ⚡ Key Highlights & Architecture

- **60 FPS Interactive Canvas Constellation**: Floating quantum nodes connected by fluid cyber energy lines with real-time cursor magnetic physics.
- **Steady Cutout Portrait with Hover Surge**: Clean feathered portrait cutout with dynamic electric cyan-blue lightning and spider-web energy matrix on hover.
- **Minimalist Luxury Preloader**: Monospaced hairline laser loading bar with smooth dual-shutter cinema opening.
- **High-Definition Light & Dark Themes**: High-contrast Apple-grade crystalline studio mode & deep obsidian cosmos mode.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/naufalhakim422/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 4. Build for production
```bash
npm run build
npm run start
```
